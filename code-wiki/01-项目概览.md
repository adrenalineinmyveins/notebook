# 项目概览

Jupyter Notebook（本仓库当前版本 `7.7.0a2`，见 [notebook/_version.py](../notebook/_version.py)）是 Project Jupyter 官方维护的 Web 端交互式计算笔记本环境。用户在浏览器中编写包含代码、公式、图表与 Markdown 的"笔记本"（`.ipynb`），代码由后台内核（如 ipykernel）执行，结果实时回显到页面。

## 版本定位

仓库 README 明确了维护策略：官方同时维护最近两个大版本——经典版 Classic Notebook v6（仅修复维护与安全问题，代码在 `6.5.x` 分支）与本仓库的 Notebook v7。v7 相对 v5/v6 是一次架构重写：

| 维度 | Classic Notebook v6 | Notebook v7（本仓库） |
| --- | --- | --- |
| 前端 | 自研 Backbone/jQuery 页面（依赖 nbclassic） | JupyterLab 4.x 组件（React + TypeScript + Lumino） |
| 后端 | 内置 Tornado 服务器 | Jupyter Server 2.x 服务器扩展 |
| 扩展形态 | nbextension（前端脚本注入） | JupyterLab 预构建扩展 + 联邦扩展（Module Federation） |
| 界面结构 | 单页 | 多页应用（MPA），见[02-整体架构](02-整体架构.md) |

v5/v6 时代的自定义扩展与 v7 不兼容，官方建议以服务器扩展或 JupyterLab 预构建扩展的形式重写。

## 仓库顶层结构

```text
notebook/            Python 包（后端服务器扩展）
├── app.py           核心：JupyterNotebookApp 与页面处理器
├── __init__.py      扩展发现入口（server/lab extension paths）
├── __main__.py      python -m notebook 入口
└── _version.py      版本号（7.7.0a2）
packages/            前端 TypeScript 源码包（12 个，Yarn workspace）
app/                 前端应用组装层（rspack 构建 + 页面模板）
buildutils/          仓库级构建/发布脚本（TypeScript）
docs/                Sphinx 用户文档源码
tests/               Python 后端 pytest 测试
ui-tests/            Playwright 端到端测试（Galata）
jupyter-config/      jupyter_server_config.d 配置片段（自动启用 notebook 扩展）
binder/              mybinder.org 在线体验环境
.github/             CI 工作流、Issue 模板、dependabot
```

各目录的完整职责说明见 [04-前端模块详解](04-前端模块详解.md) 与 [03-后端模块详解](03-后端模块详解.md)。

## 双语言 Monorepo

本仓库是"一个 pip 包 + 一组 npm workspace"的混合 monorepo：

- Python 侧以 [pyproject.toml](../pyproject.toml) 定义包 `notebook`，入口脚本 `jupyter-notebook = "notebook.app:main"`，版本号从 [notebook/_version.py](../notebook/_version.py) 动态读取。
- JS 侧以根 [package.json](../package.json) 声明 workspaces：`app`、`buildutils`、`packages/*`；包管理器固定为 `yarn@3.5.0`（Jupyter 生态中通过 `jlpm` 命令调用）。
- 两者在构建期交汇：pip 安装时，hatch 的 jupyter-builder 钩子会调用 `jlpm build:prod:release`，把前端产物写入 `notebook/static/`，随 Python wheel 一起分发（详见 [07-构建与运行](07-构建与运行.md)）。
