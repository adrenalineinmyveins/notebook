# 测试体系

仓库维持三层测试：Python 后端 pytest、TypeScript 单元测试 jest、浏览器端到端测试 Playwright（Galata）。另有严格的静态检查工具链。

## 测试全景

| 层 | 位置 | 框架 | 覆盖对象 |
| --- | --- | --- | --- |
| 后端集成 | [tests/](../tests/) | pytest + jupyter_server pytest 插件 | 路由处理器、page_config、CLI 旗标、扩展装配 |
| 前端单元 | `packages/application/test`、`packages/ui-components/test` | jest 29 + ts-jest | NotebookApp、NotebookShell、图标 |
| 端到端 | [ui-tests/](../ui-tests/) | Playwright + @jupyterlab/galata | 真实浏览器中的页面行为与视觉快照 |
| 静态检查 | 全仓库 | mypy(strict)、ruff、eslint、prettier、interrogate、zizmor | 类型、规范、文档字符串、CI 安全 |

## Python 测试（tests/）

- [tests/conftest.py](../tests/conftest.py) 提供核心 fixture：
  - `make_notebook_app`：在临时目录中搭建 `app_settings/user_settings/schemas/workspaces/labextensions` 目录结构，拷贝页面模板并生成测试用 `index.html`（内嵌 `jupyter-config-data`），构造 `JupyterNotebookApp` 实例工厂；
  - `notebookapp`：把扩展实例链接到 `jp_serverapp`（jupyter_server 插件提供的 ServerApp fixture）并完成 `initialize()`。
- [tests/test_app.py](../tests/test_app.py) 验证：扩展 flags 与 ServerApp flags 的隔离性与传递性（`test_notebook_app_flags_*`）、`/notebooks` 与 `/tree` 的渲染与重定向（含目录 → `/tree`、文件 → `/notebooks` 的互跳）、自定义 CSS handler 等。
- pytest 配置（pyproject）：`testpaths=["tests/"]`、`timeout=300`、`--doctest-modules`、warnings 升级为 error、`xfail_strict`。

运行方式：

```bash
pip install -e ".[test]"
pytest                          # 或 hatch run test:test
hatch run cov:test              # 带 coverage（source=notebook）
```

## 前端单元测试

- [packages/application/test/app.spec.ts](../packages/application/test/app.spec.ts)、[shell.spec.ts](../packages/application/test/shell.spec.ts)：在 jsdom 环境验证 NotebookApp 构造与 NotebookShell 的 add/activate 行为；各包自带 `jest.config.js` 与 `tsconfig.test.json`。
- 运行：`jlpm run build:test && jlpm run test`（根 scripts 会遍历全部 workspace）。

## 端到端测试（ui-tests/）

- 基于 Galata（JupyterLab 的 Playwright 封装），配置见 [ui-tests/playwright.config.ts](../ui-tests/playwright.config.ts)：`webServer` 自动执行 `jlpm start`（端口 8888），失败重试 1 次并记录 trace（`on-first-retry`）与视频（`retain-on-failure`）。
- 15 个 spec 覆盖主要用户旅程：`general`（冒烟）、`notebook`（全宽、NotebookTools、TOC）、`menus`（主菜单及其子菜单的视觉快照）、`mobile`（移动端视口）、`console`、`editor`、`filebrowser`、`settings`、`terminal`、`topbar`、`tree`、`links`、`layout`、`help`、`smoke`。
- 视觉快照按 `测试名-浏览器-平台.png` 存放于 `*-snapshots/` 目录（chromium 与 firefox 两套），Galata 做像素级对比；`playwright-update.yml` workflow 用于批量更新基准图。
- 测试用笔记本（empty/simple/simple_toc/autoscroll/local_links）位于 [ui-tests/test/notebooks/](../ui-tests/test/notebooks/)。

运行方式（进入 ui-tests 目录）：

```bash
jlpm install
jlpm start          # 或由 Playwright 自动拉起
jlpm test
```

## 静态检查与质量门

| 工具 | 配置位置 | 要点 |
| --- | --- | --- |
| mypy | pyproject `[tool.mypy]` | `strict = true`，检查 `notebook` 包，目标 Python 3.11 |
| ruff | pyproject `[tool.ruff]` | line-length 100；启用 bugbear、isort、pylint、bandit（S）、print 禁用（T20）等规则集；`pre-commit run ruff-check/ruff-format` |
| interrogate | pyproject `[tool.interrogate]` | 文档字符串覆盖率 `fail-under=100`（排除 tests/docs 等） |
| eslint 9 | [eslint.config.mjs](../eslint.config.mjs) | flat config，含 @jupyter 官方插件与 jest/react 插件 |
| prettier | [.prettierrc](../.prettierrc) | 全仓库 TS/JS/CSS/JSON/MD 格式化 |
| pre-commit | [.pre-commit-config.yaml](../.pre-commit-config.yaml) | 统一挂接以上工具（含 mypy 的手动 stage） |
| coverage | pyproject `[tool.coverage]` | 相对路径、排除分支样板代码 |
| zizmor | [.github/workflows/zizmor.yml](../.github/workflows/zizmor.yml) | GitHub Actions workflow 安全扫描 |
| repo-review | pyproject `[tool.repo-review]` | 仓库最佳实践检查（忽略 GH102/PC180/PC111） |

CI 中由 [build.yml](../.github/workflows/build.yml) 驱动常规矩阵（Python 版本 × 平台），[ui-tests.yml](../.github/workflows/ui-tests.yml) 驱动双浏览器端到端任务。
