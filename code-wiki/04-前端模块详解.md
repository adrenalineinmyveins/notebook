# 前端模块详解

前端源码分布在三个位置：`packages/`（12 个功能包，Yarn workspace 成员）、`app/`（应用组装与 rspack 构建）、`buildutils/`（仓库级脚本）。它们与 `@jupyterlab/*`、`@lumino/*` 生态包的关系见 [06-依赖关系](06-依赖关系.md)。

## packages/ 包总览

| 包（npm 名） | 类型 | 一句话职责 |
| --- | --- | --- |
| `@jupyter-notebook/application` | 核心库 | `NotebookApp` 应用类、`NotebookShell` 布局外壳、面板处理器、Token 定义 |
| `@jupyter-notebook/application-extension` | 扩展（23 插件） | 应用级插件：菜单、页面路由解析、工具栏、标题、Zen 模式、快捷键等 |
| `@jupyter-notebook/notebook-extension` | 扩展（12 插件） | Notebook 页专属：内核徽标、全宽、滚动输出、信任状态、元数据编辑等 |
| `@jupyter-notebook/tree-extension` | 扩展（6 插件） | Tree 页专属：文件树部件、新建菜单、文件操作、插件按需加载 |
| `@jupyter-notebook/tree` | 核心库 | `NotebookTreeWidget`（Tree 页主区 TabPanel）与 `INotebookTree` Token |
| `@jupyter-notebook/lab-extension` | 预构建扩展（2 插件） | 面向 JupyterLab 使用者：界面切换器（Notebook/Lab/nbclassic）、返回树页 |
| `@jupyter-notebook/console-extension` | 扩展（3 插件） | 控制台打开器、`/consoles` 重定向、草稿控制台（scratchpad） |
| `@jupyter-notebook/terminal-extension` | 扩展（2 插件） | 终端打开器与 `/terminals` 重定向 |
| `@jupyter-notebook/docmanager-extension` | 扩展（1 插件） | 文档打开行为定制（新标签页打开） |
| `@jupyter-notebook/documentsearch-extension` | 扩展（1 插件） | 把文档搜索绑定到 NotebookShell 部件 |
| `@jupyter-notebook/help-extension` | 扩展（2 插件） | 帮助菜单打开与 About 对话框 |
| `@jupyter-notebook/ui-components` | 组件库 | Notebook 品牌图标（jupyter.svg 等）与图标导出 |
| `@jupyter-notebook/metapackage` | 聚合包 | 汇总以上 12 包统一编译（`jlpm build:lib`） |

每个扩展包结构一致：`src/index.ts`（插件声明）、`schema/*.json`（设置系统用的 JSON Schema，随包分发并安装到 `share/jupyter/lab/schemas/@jupyter-notebook`）、`style/`（CSS，经 `styleModule` 约定被构建器收集）。

## @jupyter-notebook/application（核心库）

源码 5 个文件，全部经 [src/index.ts](../packages/application/src/index.ts) 导出：

- [src/app.ts](../packages/application/src/app.ts) — `NotebookApp extends JupyterFrontEnd<INotebookShell>`：注册 `Base64ModelFactory`、装配 mime 渲染插件、维护应用信息（`IAppInfo`：可用插件清单 + 变更信号）、暴露 `paths`（URL 与目录映射）、按视口宽度切换 desktop/mobile `format`。
- [src/shell.ts](../packages/application/src/shell.ts) — `NotebookShell implements JupyterFrontEnd.IShell`：六区布局（`main`/`top`/`menu`/`left`/`right`/`down`），管理部件的添加、激活、折叠与布局恢复；导出 `INotebookShell` Token。
- [src/panelhandler.ts](../packages/application/src/panelhandler.ts) — `PanelHandler`（按 rank 排序的面板容器）与 `SidePanelHandler`（一次只显示一个部件的侧栏容器，带关闭按钮）。
- [src/pathopener.ts](../packages/application/src/pathopener.ts) — `defaultNotebookPathOpener`：在新标签页打开指定路径的默认实现。
- [src/tokens.ts](../packages/application/src/tokens.ts) — `INotebookPathOpener` 接口与 Token，允许下游覆盖"打开文件"的行为（如改成当前标签内打开）。

类的逐方法说明见 [05-关键类与函数](05-关键类与函数.md)。

## @jupyter-notebook/application-extension（23 个插件）

单文件 [src/index.ts](../packages/application-extension/src/index.ts)（约 1400 行）按功能分组：

| 分组 | 插件（id 后缀） | 作用 |
| --- | --- | --- |
| 外观 | `logo`、`top`、`menu-spacer`、`status`、`splash`、`title`、`tab-title` | 顶部栏 Logo、菜单留白、启动画面、标题栏（含内核忙闲状态）、标签标题 |
| 布局 | `shell`、`sidepanel`、`zen`、`dirty` | 把部件装入 NotebookShell 侧栏；Zen 模式（隐藏 top/menu，schema `zen.json`）；未保存脏状态标记 |
| 路由 | `pages`、`tree-resolver`、`tree-updater` | 按 URL 解析当前页面（`shell.json`/`pages.json` schema 配置各页面路由）；地址栏与树路径双向同步 |
| 打开行为 | `opener`、`path-opener`、`paths` | 文档打开策略（notebook 在新标签、tree 页在当前标签等）；注册 `defaultNotebookPathOpener` |
| 菜单与命令 | `menus`、`shortcuts` | 经 `menus.json`/`shortcuts.json` schema 声明式构建主菜单与快捷键 |
| 渲染 | `rendermime` | 为 notebook/console 构建渲染器（含 MathJax、markdown 链接处理） |
| 其它 | `info`、`translator`、`settings-connector` | 应用信息、翻译加载、设置系统连接器（[src/settingconnector.ts](../packages/application-extension/src/settingconnector.ts)，桥接 JupyterLab 设置注册表与 jupyterlab_server 设置 API） |

schema 目录：`menus.json`、`pages.json`、`shell.json`、`shortcuts.json`、`title.json`、`top.json`、`zen.json`，全部经 `jupyter.lab.*` 字段参与 JupyterLab 设置系统。

## @jupyter-notebook/notebook-extension（12 个插件）

[src/index.ts](../packages/notebook-extension/src/index.ts) + [src/trusted.tsx](../packages/notebook-extension/src/trusted.tsx)，作用于 `/notebooks` 页：

| 插件 | 作用 |
| --- | --- |
| `kernel-logo` | 工具栏显示当前内核语言 Logo |
| `kernel-status` | 标题栏显示内核状态（busy/idle） |
| `full-width-notebook` | 全宽显示开关（schema `full-width-notebook.json`） |
| `scroll-output` | 输出自动滚动选项（schema `scroll-output.json`） |
| `checkpoints` | 快照（checkpoint）管理（schema `checkpoints.json`） |
| `close-tab` | 关闭标签前确认（schema `close-tab.json`） |
| `open-tree-tab` | 在树页新标签中打开 |
| `notebook-tools` | 侧栏 Notebook 工具面板（元数据、标签等） |
| `tab-icon` | 标签页图标 |
| `trusted` | 笔记本"信任"状态 UI（trusted.tsx，交互式提示） |
| `edit-notebook-metadata` | 编辑笔记本原始元数据（schema 同名） |
| `menu-override` | 对 notebook 页的菜单默认值做覆盖（schema `menu-override.json`） |

## @jupyter-notebook/tree-extension 与 tree（Tree 页）

- [tree/src/notebook-tree.ts](../packages/tree/src/notebook-tree.ts)：`NotebookTreeWidget extends TabPanel`，顶部标签可拖动，是 Tree 页主区容器；[token.ts](../packages/tree/src/token.ts) 定义 `INotebookTree` Token 供其它插件注入标签页（如文件浏览器、设置编辑器各占一个标签）。
- [tree-extension/src/index.ts](../packages/tree-extension/src/index.ts) 的 6 个插件：
  - `widget`：创建 `NotebookTreeWidget` 并装入 shell 主区；
  - `new`：文件浏览器工具栏的"新建"下拉（文件/文件夹/笔记本/控制台/终端，`file-actions.json` schema）；
  - `file-actions` / `file-filter-command`：文件操作与过滤命令；
  - `open-file-browser`：默认打开文件浏览器标签；
  - `load-plugins`：Tree 页专属插件的动态登记。

## @jupyter-notebook/lab-extension（嵌入 JupyterLab）

本包构建产物不是给 Notebook 自身用的，而是发布为 JupyterLab 预构建扩展（`jupyterlab.outputDir: ../../notebook/labextension`，经 `jupyter-builder` 构建）：

- `interface-switcher`（[src/index.ts](../packages/lab-extension/src/index.ts)）：在 Notebook 工具栏加入界面切换下拉——`jupyter-notebook:open-notebook`、`open-lab`、`open-nbclassic`、`launch-tree` 四个命令，依据 `PageConfig` 的 `nbclassic_enabled` 决定是否显示 nbclassic 选项（schema `interface-switcher.json`）。
- `launch-tree`：提供返回文件树页的命令与按钮（schema `launch-tree.json`）。

## @jupyter-notebook/ui-components

[src/icon/iconimports.ts](../packages/ui-components/src/icon/iconimports.ts) 聚合图标资源（含 `jupyter.svg`），向 JupyterLab 图标体系（`LabIcon`）注册 Notebook 品牌图标，供 Logo、关于框等使用。

## app/（应用组装层）

`app/` 不是发布包，而是把上面所有包组装为可部署静态资产的构建工程：

| 文件 | 作用 |
| --- | --- |
| [index.template.js](../app/index.template.js) | 前端引导模板。构建时 Handlebars 按 `jupyterlab.plugins` 展开为具体 `require(...)` 列表，生成 `build/index.js` |
| [templates/*.html](../app/templates/) | 6 个页面骨架（consoles/edit/error/notebooks/terminals/tree），含 `jupyter-config-data` 注入点；构建时经 HtmlWebpackPlugin 输出到 `notebook/templates/` |
| [rspack.config.js](../app/rspack.config.js) | 开发构建：MPL 版权插件、ModuleFederationPlugin（容器名 `CORE_FEDERATION`，共享依赖来自 resolutions + singletonPackages）、`notebook_core` splitChunks、输出 `notebook/static/` |
| rspack.prod.*.js | 生产变体：`prod`（压缩前）、`prod:minimize`（压缩）、`prod:release`（发布） |
| [style.js](../app/style.js)、[publicpath.js](../app/publicpath.js) | 样式入口（聚合各包 CSS）；运行时 publicPath 设置（`{{page_config.fullStaticUrl}}`） |

引导流程（`index.template.js` 的 `main()`）详见 [05-关键类与函数](05-关键类与函数.md) 的前端部分。

## buildutils/（仓库脚本）

[buildutils/src/](../buildutils/src/) 提供 8 个 TypeScript 脚本，编译后由根 package.json 的 scripts 调用：

| 脚本 | 命令 | 作用 |
| --- | --- | --- |
| develop.ts | `jlpm develop` | 以开发模式链接扩展与 schema（配合 jupyter-builder develop） |
| ensure-repo.ts | `jlpm integrity` | 校验/修复仓库一致性（依赖版本、schema 等） |
| get-latest-lab-version.ts | `jlpm get:lab:version` | 查询最新 JupyterLab 版本 |
| upgrade-lab-dependencies.ts | `jlpm upgrade:lab:dependencies` | 批量升级 @jupyterlab 依赖版本 |
| release-bump.ts / release-patch.ts | `jlpm release:bump` / `release:patch` | 版本号提升与回填（jupyter-releaser 调用） |
| set-workspace-version.ts | `jlpm set:workspace-version` | 统一设置各 workspace 包版本 |
| utils.ts | — | 公共工具函数 |
